# Digital Craft Studio

Quiero que construyas desde cero un sitio web profesional para mi negocio de desarrollo de software y soluciones digitales.

IMPORTANTE:

- NO reutilices diseños, imágenes, textos ni estructuras de otros proyectos.

- NO supongas que existe un proyecto anterior.

- NO copies ninguna página existente.

- Todo el diseño debe crearse desde cero.

- Quiero un resultado profesional, moderno y preparado para mostrar a potenciales clientes.

- No quiero una landing page genérica de agencia.

- Quiero que parezca el sitio de una empresa tecnológica/product studio moderno.

## OBJETIVO

El sitio debe presentar mis servicios de:

- Desarrollo de páginas web

- Aplicaciones web

- Sistemas de gestión

- SaaS

- Dashboards administrativos

- Sistemas para empresas

- E-commerce

- Automatizaciones

- Integraciones

- Soluciones personalizadas

La página debe transmitir que puedo transformar una idea de negocio en un producto digital funcional.

## ESTILO VISUAL

Usar principalmente:

- Negro

- Negro profundo

- Gris oscuro

- Blanco

- Grises neutros

El negro debe ser el color predominante.

Agregar pequeños acentos visuales elegantes, sin convertir el sitio en una página llena de colores.

Quiero una estética:

- tecnológica

- premium

- moderna

- minimalista

- profesional

- elegante

- futurista

- limpia

- con mucho espacio visual

Evitar completamente:

- diseños genéricos de plantillas

- exceso de gradientes

- exceso de colores

- imágenes de stock de personas

- fotografías genéricas de oficinas

- ilustraciones corporativas genéricas

- iconos gigantes sin propósito

## TIPOGRAFÍA

Utilizar una tipografía moderna y profesional.

La jerarquía tipográfica debe ser muy clara.

Los títulos principales deben ser grandes, fuertes y llamativos.

El texto secundario debe ser más pequeño y con buen contraste.

## ANIMACIONES

Quiero animaciones modernas pero elegantes.

Agregar:

- entrada progresiva de elementos

- desplazamientos suaves

- hover effects

- cards con movimiento sutil

- elementos que reaccionen al cursor

- transiciones suaves

- animaciones al hacer scroll

- pequeños efectos de escala

- aparición progresiva de secciones

- botones con microinteracciones

- navegación suave

NO quiero animaciones exageradas que hagan que la página parezca un videojuego.

Las animaciones deben transmitir calidad tecnológica.

## HERO

Crear un Hero muy impactante.

Título principal:

"Creo productos digitales que hacen crecer tu negocio."

Subtítulo:

"Desarrollo sitios web, sistemas y plataformas SaaS modernas, escalables y diseñadas para resolver problemas reales."

Agregar dos botones:

"Ver mis proyectos"

"Solicitar un proyecto"

El Hero debe tener un elemento visual tecnológico abstracto.

NO utilizar una fotografía de una persona.

Puede utilizarse:

- una interfaz 3D

- paneles flotantes

- código abstracto

- ventanas de aplicaciones

- tarjetas de dashboard

- elementos geométricos

- partículas sutiles

- una composición digital

La animación debe ser suave y mantenerse funcionando continuamente.

## SECCIÓN SERVICIOS

Crear una sección llamada:

"¿Qué puedo desarrollar para tu negocio?"

Mostrar tarjetas para:

1. Sitios web

   "Sitios corporativos, institucionales y páginas profesionales."

2. E-commerce

   "Tiendas online modernas preparadas para vender."

3. Sistemas de gestión

   "Paneles administrativos y herramientas para gestionar negocios."

4. SaaS

   "Plataformas digitales con usuarios, módulos y funcionalidades escalables."

5. Dashboards

   "Interfaces para visualizar información y tomar decisiones."

6. Automatización

   "Procesos automatizados para ahorrar tiempo y reducir tareas repetitivas."

Cada tarjeta debe tener:

- icono

- título

- descripción

- hover interactivo

## SECCIÓN "MIS PROYECTOS"

Esta sección es MUY IMPORTANTE.

Crear un portfolio interactivo donde pueda mostrar mis diferentes proyectos y demos.

Título:

"Proyectos y demos"

Subtítulo:

"Explorá algunos de los productos y experiencias digitales que desarrollé."

Cada proyecto debe mostrarse como una tarjeta premium.

Cada tarjeta debe tener:

- imagen o preview

- nombre del proyecto

- descripción

- tecnologías utilizadas

- categoría

- botón "Ver demo"

- botón "Ver proyecto"

IMPORTANTE:

Quiero que los demos puedan abrirse directamente desde esta página.

Por ejemplo:

[ DEMO ]

Al hacer clic en "Ver demo":

- abrir la demo en una nueva pestaña

o, preferentemente:

- abrir un modal/panel visual dentro de la página

- mostrar una vista previa interactiva

- permitir al usuario navegar por el demo

El sistema debe estar preparado para que posteriormente pueda agregar fácilmente más proyectos.

Crear una estructura de datos para los proyectos, por ejemplo:

const projects = [

  {

    title: "...",

    description: "...",

    category: "...",

    technologies: [...],

    image: "...",

    demoUrl: "...",

    projectUrl: "..."

  }

]

NO inventar proyectos reales.

Utilizar proyectos de demostración claramente identificados como placeholders hasta que yo coloque los proyectos reales.

## FILTRO DE PROYECTOS

Agregar filtros:

"Todos"

"SaaS"

"Web"

"E-commerce"

"Dashboards"

"Sistemas"

Cuando el usuario seleccione una categoría, las tarjetas deben filtrarse con una animación suave.

## SECCIÓN DEMO DESTACADA

Crear una sección especial:

"Probá una demo"

Esta sección debe sentirse diferente al portfolio.

Mostrar una interfaz de aplicación dentro de un marco de navegador.

Debe parecer que el visitante está viendo un software real.

Agregar:

- barra superior simulando navegador

- interfaz de dashboard

- cards

- gráficos

- tablas

- navegación lateral

Agregar botón:

"Explorar demo"

Esto debe ser totalmente visual y preparado para conectar posteriormente una URL real.

## SECCIÓN PROCESO

Título:

"De la idea al producto"

Mostrar 4 pasos:

01 — Idea

"Entendemos qué necesitás construir."

02 — Diseño

"Transformamos la idea en una experiencia digital clara."

03 — Desarrollo

"Construimos el producto utilizando tecnologías modernas."

04 — Lanzamiento

"Dejamos tu producto listo para usuarios reales."

Usar una línea o recorrido visual animado entre los pasos.

"¿Tenés una idea?"

"Contame qué querés construir y podemos convertir esa idea en un producto digital."

## SOBRE MÍ

Crear una sección breve y profesional.

Título:

"Detrás de cada proyecto hay una persona."

Utilizar placeholders editables para:

- nombre

- descripción

- experiencia

- especialidades

No agregar fotografías genéricas.

Dejar preparado un espacio para colocar posteriormente mi propia fotografía si quiero hacerlo.

## CONTACTO

Crear una sección de contacto moderna.

Campos:

- Nombre

- Email

- Empresa

- Tipo de proyecto

- Presupuesto aproximado

- Mensaje

Botón:

"Enviar consulta"

IMPORTANTE:

El formulario puede mostrar una confirmación visual simulada indicando:

"Mensaje preparado correctamente."

Dejar claramente preparado para conectar posteriormente con backend o servicio de formularios.

"Solicitar proyecto"
